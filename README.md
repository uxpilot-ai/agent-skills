# UX Pilot Agent Skills

Free skills for Claude Code, Codex, Cursor and other coding agents, made by [UX Pilot](https://uxpilot.ai).

| Skill | What it does | Install |
|---|---|---|
| [user-interview-guide](https://github.com/uxpilot-ai/user-interview-skill) | Writes neutral 1:1 user interview guides with probes, a moderator card and a debrief | `npx skills add uxpilot-ai/user-interview-skill` |
| [prd-generator](https://github.com/uxpilot-ai/prd-generator-skill) | Writes short PRDs that list every screen, its states, the words on it and done checks | `npx skills add uxpilot-ai/prd-generator-skill` |

Each skill lives in its own repository and carries its own licence (Apache 2.0).
